# Cut and deferred features

## Cut

| Feature | Reason |
|---|---|
| Streaks | Exposure risk from compulsive checking |
| Daily-login rewards | Exposure risk from compulsive checking |
| Variable-reward feeds | Exposure risk from compulsive checking |
| "Someone liked you" teasers | Exposure risk from compulsive checking; conflicts with principle 4 |
| Fake activity counts | Exposure risk from compulsive checking; conflicts with principle 4 |
| Global feed, public posting, mass broadcasting, advertising | Non-goals |
| Location history | Non-goal; not collected |
| Any real-name, phone-number or contacts requirement | Non-goal; no global identity |
| Accounts, analytics, cloud backup | Nothing to subpoena or leak (principle 2) |
| Dependence on app stores | Distribution is invite-only and phone to phone |

## Deferred to v1.5 (gated on the pilot)

| Feature | Reason |
|---|---|
| Gossip (store-and-forward) | Density, latency and metadata leakage are untested |
| Wi-Fi Aware/Direct transfer | Not needed for v1; gated on pilot |
| Vouching (offline) | Gated on pilot |

## Deferred to later

| Feature | Reason |
|---|---|
| UWB confirmation | Beyond v1 and v1.5 scope |
| External LoRa text relay | Beyond v1 and v1.5 scope |
| iOS | Limited background Bluetooth and distribution constraints [UNVERIFIED] |
